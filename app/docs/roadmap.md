# Roadmap – App de Finanças Android

## Visão Geral

Este documento descreve o planejamento evolutivo do aplicativo.

O desenvolvimento seguirá uma estratégia **iterativa**, onde:

- primeiro lançamos um **MVP funcional**
- depois evoluímos com novas funcionalidades
- sempre mantendo o app simples e rápido

Objetivo principal:

Publicar o aplicativo na **Google Play Store** o mais cedo possível.

---

# Versão 1.0 – MVP

Objetivo:

Criar um aplicativo funcional para controle básico de finanças.

Funcionalidades:

Autenticação

- Login com Google (Firebase Authentication)

Categorias

- Criar categoria
- Editar categoria
- Excluir categoria
- Listar categorias

Transações

- Criar receita
- Criar despesa
- Editar transação
- Excluir transação
- Listar transações

Dashboard

- Saldo mensal
- Total de receitas
- Total de despesas

Relatórios

- Gráfico de gastos por categoria
- Resumo mensal

Persistência

- Banco local com Room

---

# Critérios de Lançamento do MVP

O aplicativo poderá ser publicado quando possuir:

- login funcional
- cadastro de transações
- dashboard com saldo
- relatório básico
- estabilidade

---

# Estratégia de Evolução

Prioridades do projeto:

1. simplicidade
2. estabilidade
3. clareza de dados
4. experiência do usuário

Funcionalidades complexas só serão adicionadas após o MVP estabilizar.
